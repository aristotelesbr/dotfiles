# Dotfiles

![screenshot](public/screenshot.png)

- `nvim/` — LazyVim config → copy to `~/.config/nvim`
- `tmux-config/` — tmux config → copy to `~/.config/tmux`
- `terminal/` — iTerm2 profiles + Starship prompt
- `zsh/` — shell config and aliases

After copying `nvim/`, open `nvim` and run `:checkhealth` — you'll likely need `pip install pynvim` (Python support) and `npm i -g neovim` (Node support, optional).
